# Bundled fonts

`D2Coding-Regular.ttf` and `D2Coding-Bold.ttf` are D2Coding, version 1.3.3,
by NAVER Corporation.

- Upstream: https://github.com/naver/d2codingfont
- License: SIL Open Font License, Version 1.1 (see `OFL.txt`)
- Reserved Font Name: `D2Coding`

The OFL permits redistribution, including bundled with software, provided the
license accompanies the font files and the Reserved Font Name is respected.
`OFL.txt` in this directory is the verbatim upstream license text.

Version 1.3.3 is the latest upstream release at the time of writing
(`D2Coding-Ver1.3.3-20260725.zip`). To refresh from upstream, verify the new
release's `OFL.txt` before replacing these files.

Note: upstream `D2Coding-all.ttc` is deliberately **not** used here. It must be
installed as two separate TTFs so Windows can distinguish Regular from Bold.
See `../../scripts/register-font.ps1` and `../../README.md`.
